노선별 평균 오차 · Macro MAE 석 · 낮을수록 좋음
각 노선의 평균 오차를 구한 뒤 노선마다 같은 비중으로 평균합니다. 질문 수가 많은 노선에 전체 수치가 치우치는지 확인합니다.
0~2석 평균 오차 석 · 낮을수록 좋음
실제 도착 표시가 0~2석인 질문에서만 평균 오차를 계산합니다. 전체 평균 오차와 질문 분모가 다릅니다.
1석·3석 이상 과대예측 % · 낮을수록 좋음
실제 0~2석인데 예측을 정답보다 각각 1석 이상, 3석 이상 높게 한 비율입니다. 3석 이상인 경우는 1석 이상에도 포함됩니다.
0석 감지율 % · 높을수록 좋음
실제 0석인 질문 중 좌석 예측을 2석 미만으로 낸 비율입니다. 정확히 0석이라고 예측한 비율이나 탑승 성공 확률이 아닙니다.

연구 판단

평균 오차가 작다고 바로 선택하지 않습니다

각 연구에서 결과를 보기 전에 비교 기준을 고정했습니다. 전체·노선별 오차와 좌석 부족 상황의 과대예측, 0석 감지율을 함께 확인합니다. 연구마다 바꾼 기준은 해당 연구 상세에 남겼습니다.

조건을 통과한 후보를 다음 실험의 연구 기준으로 선택할 수 있습니다. 선택되지 않은 모델도 삭제하지 않고 목록에 남겨 평균 오차와 위험 사이의 차이를 비교할 수 있게 했습니다. 연구 기준 후보 선택은 운영 예보 반영과 별개입니다.

해석의 범위

새 기간의 성능은 아직 확인되지 않았습니다

  • 같은 개발 평가 자료를 여러 번 사용했습니다. 반복 비교에서 좋아진 결과가 새로운 기간에도 유지된다고 단정하지 않습니다.
  • 현재 표시된 연구는 운영에 채택되지 않았습니다. 기존 출발 연구의 기준 모델이나 점수와 직접 비교하지 않습니다.
  • 분류 점수나 여러 예측의 조합을 검증된 좌석 확률 분포로 해석하지 않습니다. 확률을 평가한 파일럿 모델은 별도 범위로 표시합니다.
  • 입력 원자료의 전체 행 수, 학습 질문 수와 정답 방문 수는 다른 단위입니다. 각 단계에서 실제로 사용한 분모를 기준으로 읽어야 합니다.
