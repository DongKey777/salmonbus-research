현재 좌석을 그대로 유지하는 기준선, 절대 오차 회귀, 35% 분위수 회귀, 그리고 두 회귀에 같은 좌석 구간 판별기를 결합한 방식입니다.

회귀 모델 두 개와 공유 판별기 한 개를 새로 학습했습니다. 결합 방식마다 판별기를 다시 학습하지 않았습니다.

현재 상황을 나타내는 기본 특징만 사용

선언된 관측 시각을 기준으로 입력을 구성했습니다. 운영 DB에 실제로 기록된 시각까지 재현한 검증은 아닙니다. 도착 정답에서 만든 과거 이력 특징과 기존 저장 모델은 사용하지 않았습니다.

부족한 좌석을 더 신중하게 예측

평가는 질문마다 같은 비중입니다. 학습 가중치가 검증 점수의 가중치로 이어지지는 않습니다.

결합 결과는 하나의 좌석 수 추정치

판별기의 0석·1~2석·3석 이상 점수에 학습자료의 구간별 대표값과 회귀 예측을 결합합니다.

분류 점수는 보정된 확률이 아니며, 결합된 분위수 예측도 전체 분포의 35% 분위수로 해석할 수 없습니다. 개인 탑승 확률은 계산하지 않았습니다.
