보호된 H 자료의 실제 값을 제거한 과거 관측에서 좌석 변화와 앞 차량 상태를 다시 구성했습니다. 수요 통계는 TRAIN 경계와 첫 H 시작 중 이른 시각 이전으로 고정했습니다.

과거 출발·통과 후 관측의 수요 통계는 입력 특징으로 사용합니다. 새 학습과 평가의 정답은 목표 정류장의 첫 도착 표시 잔여석입니다.

두 연구 기준은 기존 도착 연구에서 학습한 판별기와 좌석 예측기를 유지합니다. 31개 입력 모델은 질문마다 같은 학습 비중을 사용하며, 좌석 부족 사례에 비중을 더 준 연구 후보와 학습 방식이 다릅니다.

분포와 평가값

31개 입력 모델의 좌석 분포 평균을 점예측으로 평가합니다. 보정된 탑승 확률이나 개인의 탑승 성공률로 해석하지 않습니다.

지표를 읽는 방법

평균 오차(MAE)는 실제 표시와 예측의 차이를 절댓값으로 평균한 좌석 수입니다. 3석 이상 과대예측률은 실제 0~2석인 질문 중 예측값이 실제보다 3석 이상 큰 비율입니다. 0석 감지율은 실제 0석인 질문 중 예측값이 2석 미만인 비율이며 높을수록 좋습니다.

RMSE는 큰 오차에 더 민감하며, 평균 편향이 양수면 실제보다 많게 예측한 경향입니다. —는 해당 사례가 없어 계산하지 못했다는 뜻입니다.
