새 후보가 바꾼 학습 방식

  1. 절대오차: 오차 크기를 그대로 줄입니다. 조건부 중앙값을 겨냥하므로, 큰 오차를 제곱해 반영하는 기존 HGB와 학습 목표가 다릅니다. 중앙값은 조건이 비슷한 정답 분포의 가운데 값입니다.
  2. 25% 분위수: 조건부 정답 분포의 아래쪽 25% 지점을 겨냥합니다. 같은 크기의 오차라면 과대예측에 과소예측보다 3배 큰 벌점을 주는 손실입니다. 좌석 수 하나를 내며, 25%라는 숫자가 탑승 성공 확률이나 검증된 보장 수준을 뜻하지 않습니다.
  3. 0~2석 4배 가중: 제곱오차를 사용하되 실제 도착 표시 0~2석인 학습 질문 4,881개에 나머지 질문의 4배 비중을 줍니다. 전체 학습 가중치 평균은 1이 되도록 정규화했습니다. 고정한 비중의 영향을 보는 실험이며, 실제 서비스 비용의 최적 비율로 정한 값은 아닙니다.

중앙값·분위수 손실도 관측된 희소 구간의 정확도를 보장하지 않습니다. 여섯 모델 모두 점예측 모델이므로 확률 보정이나 Brier 점수는 계산하지 않았습니다. 아래 파일럿의 분포 모델은 별도 자료의 결과입니다.
