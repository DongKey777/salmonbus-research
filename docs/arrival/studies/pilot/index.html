HGB는 어떻게 예측하나

HGB는 여러 결정 트리를 차례로 학습하는 회귀 모델입니다. 결정 트리는 현재 좌석이나 예측 거리 같은 입력을 기준으로 자료를 나누어 좌석을 예측합니다. 다음 트리는 앞선 트리들이 남긴 예측 오차를 보완합니다. 입력값을 여러 구간으로 묶은 히스토그램을 이용해, 자료를 어디서 나눌지 찾습니다.

세 후보 모두 학습 자료(TRAIN)만으로 학습했습니다. 오차를 제곱한 값을 줄이도록 학습하므로 큰 오차에 더 민감합니다. 개발 평가 자료(DEV)는 이렇게 만든 모델을 같은 질문으로 비교하는 데 썼습니다. 이번에는 이미 사용한 개발 자료를 다시 평가했으므로, 새로운 기간의 성능을 확인한 결과는 아닙니다.

특징만 달리한 세 후보

  1. 기본 특징 10개: 현재 잔여석, 예측 거리, 시각, 노선 등 현재 상황을 사용합니다. 과거 순변화 통계 없이 어느 정도까지 예측하는지 보는 기준입니다.
  2. 기본 특징 + 순변화, 총 18개: 기본 특징에 목표 정류장 직전까지의 순변화와 목표 정류장의 과거 통계 등 8개를 더합니다. 이 통계가 예측에 도움이 되는지 확인합니다.
  3. 목표 정류장의 과거 통계 제외, 총 15개: 전체 18개 중 목표 정류장의 순변화 평균·표본 수·통계 누락 여부 3개만 뺍니다. 중간 구간의 순변화를 유지한 채 목표 정류장 자체의 과거 통계가 더하는 효과를 살펴봅니다.

모델 설정은 같게 두고 각 후보를 한 번씩 학습했습니다. 가장 작은 오차를 기록했다는 사실과 모델을 채택할 근거가 충분하다는 판단은 구분합니다.
